Dota Translator

Ready to play

Nothing to sign up for and nothing to pay. Restart Dota once after installing - the game picks up its chat feed only when it starts - then play in Borderless Window or Windowed mode (not Exclusive Fullscreen). Translations appear above the game's chat.

Your teammates write

Their chat is shown in English either way; this decides which language is picked out of the chat and which one Ctrl+Enter writes.

Your own messages: Ctrl+Enter in Dota's chat translates them

Type in the game's chat as always, then press Ctrl+Enter instead of Enter. Plain Enter sends it exactly as you typed it. (It follows what they really type: if the chat turns out to be in another of these languages, Ctrl+Enter writes that one.)

Text size, in its own box

Above Dota's chat the text copies the game's size; this is for the separate box.

There are more settings than these - timing, position, the model - in a file called config.json, for people who like that sort of thing.

Chat lines that need translating go to this project's translator (translate.dotatranslator.live) and on to Google's Gemini. Nothing that is said is logged there. Lines already in English never leave your PC. The source is public, so anybody can check that.
