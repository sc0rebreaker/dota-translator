Get your free Gemini key

Dota Translator has no server and no account. The translating is done by Google's Gemini, on a key that is yours. Getting one takes about two minutes and no card.

Free - no card asked for 2 minutes You need a Google account

Open Google AI Studio

Go to aistudio.google.com/apikey and sign in with any Google account. The first time, it asks you to accept its terms.

Create a key - or use the one it made you

New to AI Studio? Once you accept the terms it makes a project and a key for you, and the key is already in the list. Skip to step 3.

Otherwise, press Create API key, top right. It asks which project the key belongs to:

  • Pick (or create) a project that has no billing set up. That is what keeps it on the free tier.
  • Any name will do - "dota" is fine.
Why no billing? A project with prepaid billing does not fall back to the free tier when its credit runs out - it stops, with "prepayment credits are depleted". A free project never asks for money at all.

Copy the key

Click the key in the list and copy it. It is one long line of letters and numbers.

Treat it like a password. Anyone who has it can use up your free quota. Don't post it, don't paste it into a chat, don't put it in a screenshot. If it ever gets out, delete it on the same page and make another - that takes a minute.

Paste it into Dota Translator

Start Dota Translator. The first time, it opens a window asking for the key. Paste it in and press Check and save.

The key is saved on your PC only, encrypted by Windows for your user, and is sent to Google and nobody else. To change it later, click the Dota Translator icon in the system tray, by the clock.

Rather use a file? Put it in config.json as geminiApiKey, or set the environment variable GEMINI_API_KEY, which never touches the disk.

Play

Load into a match and have somebody type in Russian. The line appears above Dota's chat at once and turns into English about a second later. Dota has to be in Borderless Window or Windowed mode (Settings, Video), not Exclusive Fullscreen, for anything to be drawn over it.

If it does not work

"prepayment credits are depleted"

The key belongs to a project with billing switched on and no credit left. Make a new key in a project that has no billing account (step 2). The free tier is plenty for Dota chat.

"Your project has been denied access" (403)

This has happened with a brand-new project that otherwise looked fine: it would list the models and refuse every request. Create the key in a different project and it works.

"You exceeded your current quota"

The free tier allows about 15 requests a minute. Dota Translator counts its own requests and, when chat gets busy, sends several lines in one - so this should only appear if the same key is being used by something else at the same time.

"Google does not recognise this key"

Usually a character lost while copying. Copy the key again with the Copy button in AI Studio rather than by selecting it, and paste it again.

Does Google see my chat?

The lines that need translating are sent to Google's Gemini API under your key, and that is all that is sent: no account name, no match, and nothing that was already in English. Google's terms for the free tier apply to what it does with them.
