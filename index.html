And now you can answer

Type in Dota's own chat, the way you always do, and press Ctrl+Enter instead of Enter. About a second later it is said - in their language. Plain Enter still sends exactly what you typed.

The same line every time: what you have said once is remembered on your PC, so the same English is always the same Russian, at once and at no cost - in a plain text file a friend who speaks the language can correct. How it works: the app presses a few keys for you - select, copy, paste, Enter - only when you press Ctrl+Enter and only while Dota is the window in front. Nothing is written to the game. It needs most of a second, so it is for "buy wards", not for a call in the middle of a fight. More in the catch.

Run Dota borderless

Settings, Video, Display Mode: Borderless Window. The translation is a window drawn over the game, and an exclusive-fullscreen game does not let other windows on top of it.

Install it and paste the key

Download, run the installer, and paste your key into the window that opens. It tries the key before saving it. Restart Dota once, so the game notices its new chat feed, and play.

Windows only. The installer is not code-signed, so Windows asks "are you sure?" the first time: More info, then Run anyway - what that looks like, and why it is normal. Once it has your key it lives in the tray, by the clock. Alt+D hides it, Alt+Shift+D quits.

The catch, up front

  • It does not read Dota's memory. Chat comes from Game State Integration, the feed Valve built into the game for overlays and stream tools: the game sends it to your own PC. The app never opens the game's process, injects nothing and changes none of its files. To switch the feed on it writes one small config file into Dota's folder, and Dota has to be restarted once to notice it.
  • It looks at two small spots of your screen. The feed says which seat spoke, not which hero. So when somebody new speaks, the app captures the portrait beside the newest chat line - about 56 by 40 pixels - and if that is unclear their tile in the top bar, compares it with the portraits in your own Dota install, and throws it away. Only while Dota is in front; nothing is saved or sent anywhere. It can be switched off, and then other players are shown by colour only.
  • Other players have no names. The feed does not carry them. You see their hero portrait and their colour - Pink, Teal - which is how most people tell who spoke anyway. Your own lines carry your name.
  • It used to read memory, and that is why it was rebuilt. Versions up to 0.3.7 read the chat out of the running game. In February 2023 Valve banned over 40,000 accounts for cheats that read hidden data from the client, and wrote that any application reading the client can get an account "permanently banned", chat-only or not. No ban was ever reported for this app - but when a player pointed out that the game's own feed carries chat, the memory reader was taken out. It is not in the download.
  • If you use Ctrl+Enter to answer, it presses keys for you. Select, copy, paste and Enter, sent through Windows the way a macro key sends them - once, when you ask, and never unless Dota is in front. Nothing is written to the game. It can be switched off, and then the app sends the game nothing at all.
  • Valve has not approved it. It uses Valve's own feed and gives no advantage in the game, but nobody at Valve has reviewed this app, and that is true of every third-party tool you run beside Steam.
  • A Dota update could change the feed or move the chat on screen. Then the app updates itself; until it does, the text may sit in the wrong place or portraits may be missing. The translations themselves do not depend on either.

Like any third-party program: use it at your own risk.

Questions

Is it really free?

Yes. No subscription, no account, no trial. It uses your own Gemini key, and Google's free tier covers normal play: only lines you can't read are sent, busy moments share one request, and repeats cost nothing. If it wins you a game and you feel like it, you can buy me a coffee on Ko-fi - it changes nothing about what you get.

Will it slow my game down?

It should not. The game sends its chat to the app once a second; the app does not search or read the game at all. When somebody new speaks it compares one thumbnail-sized picture, which takes about 30 milliseconds.

Is the download safe? It is an unsigned .exe from a stranger.

Fair. So it is set up to be checked rather than believed: every installer is built by GitHub from the public source, not on my PC; it needs no administrator rights; it talks only to Google, GitHub and Valve's image server; and the fingerprint of each release is published. The download page lists all of it, and explains the blue Windows warning, which means "unknown publisher", not "something was found".

Can I get banned?

Nobody can promise anything about somebody else's rules, so here is what it does instead: it does not read or write the game's memory, it injects nothing, and it gets the chat from the feed Valve built for tools like overlays. See the catch for the rest - two small screen captures, and key presses if you use Ctrl+Enter. Valve has not reviewed this app.

Where does my chat go?

The lines that need translating go to Google's Gemini API under your own key. There is no server of ours in between, nothing is logged or collected, and English lines never leave your PC. Hero portraits are read from your own Dota install; if one cannot be found there it is fetched from Valve's own image server instead. The small screen captures never leave your PC and are not saved. The only other thing it fetches is one small settings file from this project's GitHub, so that a change in Dota's chat layout can be fixed without a reinstall.

Can I answer them in Russian?

Yes. Type English in Dota's chat and press Ctrl+Enter instead of Enter: it is sent in the language your teammates have been typing in, about a second later. A setting turns it round (Russian → English). The translation is a model's, tuned for Dota chat; if a Russian speaker tells you a line is off, say so in an issue - that is how it gets better. See answering.

Sometimes lines stay in Russian. Is it broken?

Probably not. The translating is done by Google on its free tier, and when that is overloaded it answers slowly or not at all - usually for minutes, now and then for an hour. The app keeps showing every line as soon as it hears it, exactly as it was written, tells you once that Google is not answering, and carries on by itself when it is back. Nothing to restart.

Only Russian?

Russian is what it is built and tuned for. Chinese is translated too, out of the box, because so many of the voice lines people paste into chat are Chinese. Greek, Korean, Arabic and Thai can be switched on in the settings; those are less tested.

Does it update itself?

Yes. It looks for a new version when it starts and every few hours after, downloads it quietly, and installs it the next time you close the app - never in the middle of a match. The version you are running is in the tray icon's menu. One catch: a copy older than 0.2.6 only looks when it starts, so if yours has been running for days, quit it from the tray and open it again once.

Can I check what it does?

Yes, all of it. The full source is on GitHub, and the installer is built there from that source by an automated job, in the open, not on somebody's PC. The part that listens to the game's feed is gsisource.js, the screen capture is one plain-text file, rowgrab.ps1; the part that handles your key is keycheck.js.

Is it open source?

The source is public and free to use, read and change for non-commercial purposes (PolyForm Noncommercial). Strictly that makes it source-available rather than open source: a paid product may not bundle it.

Can I ask for a change, or make one myself?

Yes to both. The quickest way is the feedback form: one box, no account needed, and the app's tray menu opens it too. Or open an issue on GitHub to report a bug or ask for a feature - a wrong translation, a screen where the text sits in the wrong place, a language you want. And the source is public, so if you would rather fix it yourself, pull requests are welcome.
