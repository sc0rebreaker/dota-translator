From Google AI Studio: two minutes, no card. The free tier is plenty for Dota chat. Step by step, with pictures →

Run Dota borderless

Settings, Video, Display Mode: Borderless Window. The translation is a window drawn over the game, and an exclusive-fullscreen game does not let other windows on top of it.

Install it and paste the key

Download, run the installer, and paste your key into the window that opens. It tries the key before saving it, then finds the chat by itself when a match loads.

Windows only. The installer is not code-signed, so Windows asks "are you sure?" the first time: More info, then Run anyway - what that looks like, and why it is normal. Once it has your key it lives in the tray, by the clock. Alt+D hides it, Alt+Shift+D quits.

The catch, up front

  • It reads Dota's memory. Read-only: it never writes to the game, injects nothing and touches none of its files. You can check: the reader is one plain-text file.
  • Valve has never said whether that is allowed. It was asked directly in 2024 and the question was closed without an answer.
  • No documented ban is not the same as safe. Nobody has reported a VAC ban for read-only access. That is a weaker claim than "it is fine", and it is the only one anybody can honestly make.
  • It is an unsanctioned third-party tool. Not one of the overlays Valve permits: those do not read the game's memory, and this does. Tools like it are widely used and work, and the people using them carry the risk themselves.
  • A Dota patch can break it until its chat offsets are updated. The app fetches those from this project's GitHub each time it starts, so a fix reaches you without reinstalling anything. It is built to fall back to a slower way of reading chat when that happens, rather than going dark.

Use it at your own risk, and not on an account you would mind losing.

Questions

Is it really free?

Yes. No subscription, no account, no trial. It uses your own Gemini key, and Google's free tier covers normal play: only lines you can't read are sent, busy moments share one request, and repeats cost nothing.

Will it slow my game down?

It should not. It reads the game's own chat list - a few kilobytes, four times a second - which measures at 0.3% of one CPU core. The one heavier moment is when it first finds that list in a match: about ten seconds of reading, at low priority, once.

Can I get banned?

Nobody can promise you won't. See the catch: it is read-only and no ban for that has been documented, but Valve has not approved it and the Steam agreement covers any third-party tool.

Where does my chat go?

The lines that need translating go to Google's Gemini API under your own key. There is no server of ours in between, nothing is logged or collected, and English lines never leave your PC. The only other things it fetches are hero portraits, from Valve's own image server, and one small settings file from this project's GitHub, so that a Dota patch can be fixed without a reinstall.

Only Russian?

Russian is what it is built and tuned for. Chinese is translated too, out of the box, because so many of the voice lines people paste into chat are Chinese. Greek, Korean, Arabic and Thai can be switched on in the settings; those are less tested.

Does it update itself?

Yes. It looks for a new version when it starts and every few hours after, downloads it quietly, and installs it the next time you close the app - never in the middle of a match. The version you are running is in the tray icon's menu. One catch: a copy older than 0.2.6 only looks when it starts, so if yours has been running for days, quit it from the tray and open it again once.

Can I check what it does?

Yes, all of it. The full source is on GitHub, and the installer is built there from that source by an automated job, in the open, not on somebody's PC. The part that reads the game is one plain-text file, memscan.ps1; the part that handles your key is keycheck.js.

Is it open source?

The source is public and free to use, read and change for non-commercial purposes (PolyForm Noncommercial). Strictly that makes it source-available rather than open source: a paid product may not bundle it.
